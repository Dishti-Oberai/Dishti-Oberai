## 🛠 What I'm building

<table>

### [Tokenetics](https://github.com/Dishti-Oberai/tokenetics)
**Less burn, same brain.**

A deterministic 11-stage pipeline in front of Anthropic API calls that trims what's sent *and* what comes back — no model calls in the core path.

**~53% cheaper** on repeated multi-turn conversations, measured across 4 live API runs.

<img src="https://github.com/Dishti-Oberai/tokenetics/raw/main/docs/screenshots/dashboard-overview.png" width="100%" alt="Tokenetics dashboard showing measured token savings">

### [Branch-Out](https://github.com/Dishti-Oberai/branch-out)
**Coding sessions as a tree, not a line.**

Branch into parallel auto-scored approaches, backtrack without losing work, question past decisions, merge two branches into one.

Web app + **VS Code extension**, benchmarked on 80 tasks with real unit-test scoring.
